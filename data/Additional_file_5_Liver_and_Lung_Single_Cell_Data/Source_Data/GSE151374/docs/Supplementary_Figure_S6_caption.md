# Supplementary Figure S6. Pooled-library single-cell reanalysis of nintedanib response in bleomycin-exposed mouse lung (GSE151374).

Role convention: *Fgfr1* is the prespecified exposure-proximal target track displayed in this lung dataset; *Fbp1* is a downstream P1 DILI phenotype anchor and *Gsta1*/*Otc* are downstream P2 DILI phenotype anchors, not drug targets.

Each plotted inferential observation is one independently prepared 10x library pooling three mice (n=3 libraries per condition and time point); cells are never treated as independent replicates. **(A)** Number of QC-retained cells in each pooled library. **(B)** Median UMI count versus median detected genes among retained cells, summarized once per library. **(C)** Principal-component analysis of all-retained-cell library pseudobulks. Circles indicate day 7 and squares day 14. **(D)** Broad marker-rule lineage composition of every pooled library. **(E)** Macrophage-stratum fractions in day-matched BLM and BLM+nintedanib libraries; points are pooled libraries and black bars show mean ± SEM for visualization. Inferential statistics use pooled-library proportions. **(F)** Principal-component analysis of macrophage-stratum pseudobulks. **(G,H)** Exploratory macrophage-pseudobulk gene-level contrasts of BLM+nintedanib versus BLM at days 7 and 14, respectively; the dashed line denotes nominal P=0.05. Two-sided Welch tests were BH-corrected within day; no feature met q<0.10. **(I)** Nintedanib-minus-BLM differences in five prespecified macrophage program scores, with Welch 95% confidence intervals; exhaustive 3-versus-3 permutation tests are provided in the source table. No program met multiplicity-controlled significance. **(J)** Absolute log2(CPM+0.5) abundance of prespecified target and phenotype tracks in macrophage pseudobulks; low/absent *Fbp1*, *Gsta1*, and *Otc* rows are retained as explicit detectability results. No pool-level composition, module, or candidate-track result met exact-permutation BH significance; the minimum attainable two-sided exact P value was 0.10. This experiment provides pulmonary-response context only and is not a liver-toxicity experiment.
